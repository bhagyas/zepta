# License

zepta is open source (MIT). No license activation is required.

## zepta license status

Show license status.

### Examples

```bash
zepta license status
zepta license status --json
```

### JSON output

```json
{"status":"active","message":"Open source: Active forever"}
```

---

## zepta license activate / deactivate

Stubs. zepta does not require activation.

### Examples

```bash
zepta license activate
zepta license deactivate
```

Both print a message that zepta is open source and no activation is required.
