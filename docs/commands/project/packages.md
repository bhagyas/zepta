# Swift packages

Manage Swift Package Manager dependencies (stub).

zepta provides stub subcommands for `project packages`. Only `list` is implemented (returns empty or not implemented message); other subcommands print a "not implemented" message.

## Examples

```bash
zepta project packages list
zepta project packages list --json
```

## Subcommands (stubs)

| Subcommand | Description |
|------------|-------------|
| `list` | List packages (stub; may return empty) |
| `add` | Not implemented |
| `remove` | Not implemented |
| `resolve` | Not implemented |
| `update` | Not implemented |
| `clear` | Not implemented |
| `link` | Not implemented |

## Options

| Option | Description |
|--------|-------------|
| `--json` | Output JSON |
| `--examples` | Show usage examples |
